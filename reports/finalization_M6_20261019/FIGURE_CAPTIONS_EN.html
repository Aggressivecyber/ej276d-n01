Figure captions and evidence scope

All numerical panels use previously verified saved results. No response model was rerun for figure generation. Conditions refer to two original model heads and three noise hypotheses, not independent acquisitions. Figures are supplied as PNG and SVG.

Figure 1. Conditional calibration and complete hard observation. Image. A prepared 384-sample source event drives the frozen reference response, a constrained mean correction and a linear residual transport. Electronics, ADC, baseline subtraction, first-argmax and dynamic cropping produce the 256-sample native observation. Reference-area and deterministic-peak constraints act before this nonlinear observation chain. S is a closed research candidate with failed native protection.

Figure 2. Executed calibration variants and their protection tradeoff. Image. Population mean voltage and full-range PSD empirical CDF compare REAL with M0, BASE054, 070 and S for head 0 / fast; each simulated curve uses all 6,593 parents and REAL uses 21,047 records. Gain and protection panels retain all six head/noise conditions. Improvements are relative to M0. The QPSD limit is the original 0.05T increase allowance. These are four existing variants under one development protocol. The planned P0/P1/CPU-Net/N01 comparison has not run.

Figure 3. Native tail decomposition and mean-peak instability. Image. Signed population-mean terms from the saved 071 and S decompositions distinguish fixed-window mean, random and ADC changes from movement of the BASE054 window. Each condition contains 6,593 original events. Lower panels show top-two deterministic-mean peak-gap CDFs and peak reselection after ADC with stochastic residual and electronics disabled. S has 5,374 sub-code gaps and 4,460 ADC-only reselections; BASE054 has 294 and 92. Decomposition terms are path-specific algebraic identities, not causal percentages; stagewise event counts may overlap.

Figure 4. Conditional morphology across common output-Q bins. Image. Conditional means of peak voltage, rise time, FWHM and guarded PSD use frozen common REAL-derived Q bins. Each system enters bins using its own output Q; x coordinates are REAL median Q values. Lines show head 0 / fast, while the S envelope spans six head/noise conditions and is not a confidence interval. Exact bin population, defined and undefined counts for every plotted quantity and all 192 system-condition cells are supplied in the conditional CSV. This figure does not contain the planned event-content intervention experiment.

Figure 5. Population covariance and separately verified software replay. Image. Heatmaps display already saved covariance of the first 64 observation samples within output-Q bin 4, separately for REAL, M0 and S, for the displayed head 0 / fast condition. A common color scale preserves comparison. These matrices mix different input events and are not same-parent stochastic-kernel covariance. The variance decomposition identifies the missing repeated-parent component. The validation panel reports 396 legacy, 96 S-golden and 31 replay tensor checks, all byte-exact. The planned 128-parent × 64-draw study, new confirmation and S-specific C2ST remain unrun.

Figure 6. Evidence coverage for the current method report. Image. The table separates executed numerical and development checks from experiments that have not run: new MC confirmation, a fair four-system comparison, full-pipeline grouped validation, repeated-parent kernel evaluation, input intervention, new-endpoint C2ST and alternative tail-window tasks. An unavailable experiment carries no numerical score. The figure is an evidence map, not a held-out performance result.
