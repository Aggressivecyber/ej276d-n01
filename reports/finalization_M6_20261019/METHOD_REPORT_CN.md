# 读出过程感知的条件随机波形校准：S 方法与负结果

日期：2026-10-19。科学状态：`response_match_not_established`。本报告总结已经执行的 S 校准、原生读出分解、完整结果复算和研究 API 验证。S 改善了波形与联合形态距离，但六条件均未守住原生读出保护；没有可进入新确认的合格端点。

## 1. 数据、目标与参照

目标是将完整 SOURCE 事件映射为依赖输入的随机探测器响应，并经真实的软件读出链得到 256 点观察波形。开发人口固定为 6,593 个 SOURCE 父事件和 21,047 条 REAL 记录。REAL 的 422 个逻辑组属于同一次历史采集。两批事件不配对；Q 是软件积分代理，单位 V ns，没有被标定为中子入射能量。父 ID 只保存映射，不进入模型。

本次评价沿用两个冻结随机头和 fast、slow、common_level 三种噪声延展假设。六条件是模型与噪声敏感性条件，不能算六次独立采集。固定原人口、原 FIT 随机流与原观察定义，保存 M0、BASE054、070、S 共 24 份结果，每份 6,593 行。M0 是主要历史参照；BASE054 仅具有有限收益；070 和 S 都是保留的负结果。该四变体表不是 P0/P1/CPU-Net/N01 的公平训练比较。

## 2. 从输入到硬观察量

输入为准备好的 float64、384 点 clean SOURCE 电压载体。A0 给出冻结确定性参考，原 M0 随机头提供形状残差，BASE054 给出本次均值起点 m。共享条件 profile 与 069 交点映射定义期望形态；推理不读取某个 REAL 事件作为配对目标。

S 在 [110,176) 的 66 个点上使用 24 个三次 B 样条列。掩码保留原正均值且位置不早于 p−14 的支撑，p 是 m 在 [112,144) 中的 first-argmax。修正的外段、非许可支撑、两端值和一阶差分均为零；参考 front 与 tail 的积分修正为零。24 是基列数，实际自由度为等式零空间维数，不能一律写成 24 个独立参数。

令 G 为该零空间中的离散基，d=Gz，v 为期望形态相对 m 的局部变化。均值求解为

\[
\min_z\;\tfrac12(Gz-v)^TD^TD(Gz-v)
+\lambda_s\|S_2Gz\|^2+\lambda_r\sum_j w_j\|R_{p+j}Gz\|^2.
\]

其中 D、S₂、R 分别按参考幅度、二阶差分尺度及 Q/tail 尺度归一化。冻结的两头尺度相同：A_ref=0.15554293597289215 V，Q_ref=3.66896364775571 V ns，T_ref=0.6947215402546918 V ns；由既有 TRAIN BASE054 均值统计获得。邻峰半径由候选评分前的 071 规则绑定为 4；λs=0.01，λr=1。邻窗约束为软惩罚。

不等式保留正支撑和确定性峰顺序。实际数值配置对正值采用 min(原值,10⁻¹⁰ A_ref) 下界；p 前/后的峰差分别采用 min(原差,10⁻⁸ A_ref) 和 min(原差,10⁻¹⁰ A_ref)，原有并列的下界仍为零。该数值修订在 S 的 REAL 评分之前冻结。OSQP 1.1.3 使用 float64，eps_abs=eps_rel=10⁻¹²、最多 10,000 迭代、polishing 开启、warm start 关闭。组装后再核验严格 first-argmax 和原单位守恒。没有按候选得分回调这些常数。

随机残差同步变换。用只依赖输入与确定性均值的同一合法子空间和正定度量，将 (W_x−I)r 线性投影后加回 r，得到 r′=L_xr。对固定 x，若原残差条件均值为零，则 E[r′|x]=0，Cov(r′|x)=L_x Cov(r|x)L_xᵀ。这是 ADC 前的线性性质。均值 QP 的不等式 active set 没有应用到每个随机实现上。

最后将 m′+r′ 与冻结 005 电子学和对应噪声延展相加，经原 14 bit ADC、前 100 点基线扣除、[112,144) first-argmax 和动态裁窗。Q 窗为 [p−16,p+240)，tail 窗为 [p+30,p+240)，front=Q−tail，采样间隔为 1 软件 ns。完整原生波形及未定义、截尾、峰与 ADC flags 均保留。

## 3. 指标的含义

[完整表](data/METRICS_ALL_CONDITIONS.csv) 中的数值是生成分布相对 REAL 的距离，不是两批数据的均值。`wave` 沿用冻结的多视图 W1 组合：0.50 切片项、0.25 坐标项、0.25 短延迟联合项；电压、归一形状、差分、曲率和平滑差分使用原 TRAIN 归一化。它不是早期训练使用的 energy 目标。`joint_morphology` 使用原 21 维联合观测、21 坐标方向与 64 个冻结随机方向。Q/front/tail 的一维距离为 V ns，峰高距离为 V，rise/FWHM 距离为 ns，PSD 为无量纲。

研究尺度 T 来自 013 人工 gain/tail/noise/width 扰动，`hardware_calibrated=false`。保护主要按相对 M0 的距离增量不超过 0.05T 判断；负波瓣面积沿用 039 的不得变坏规则。绝对 D/T、增量 ΔD/T 和实际原单位值分别保留。[保护失败卡](data/PROTECTION_FAILURE_CARD.csv) 与[负波瓣卡](data/NEGATIVE_LOBE_FAILURE_CARD.csv)不能相互抵消。

[条件均值表](data/CONDITIONAL_MEANS_AND_DENOMINATORS.csv)使用冻结共同输出 Q 箱，各系统按自身 Q 入箱。每格明确列出 SOURCE/REAL 人口及各量定义/未定义分母。图中横坐标为该箱 REAL 的 Q 中位数，不代表事件配对。所有未定义值保持原定义，未以零补齐。

13,186 个均值 QP 全部完成。参考积分最大残差为 6.83×10⁻¹⁶ V ns，确定性峰和支撑检查通过。六条件均失败于 QPSD、front、tail、guarded PSD 和负波瓣面积距离。负波瓣距离相对 M0 增加 0.278–0.340 mV ns。全部结论仍是固定原人口、原 FIT 库的开发结果；没有新确认区间。

最直接的读出限制出现在均值本身。S 的 5,374/6,593（81.51%）个父事件前两峰差小于 1 个 ADC 码，BASE054 为 294/6,593。关闭随机残差和电子学，仅施加 ADC 后，S 的 4,460/6,593（67.65%）行换峰，BASE054 为 92/6,593。原浮点峰检查通过与 ADC 后选峰稳定是两件不同的事。

完整随机路径中，BASE054→S 的终态峰改变 3,421–3,455 行。终态峰不同组中，均值修改对竞争峰的平均优势为 +13.40 至 +13.86 mV，随机修改为 −0.23 至 −0.28 mV。固定路径下，窗口移动是 tail 平均增量的主要正项。071/S 分解使用带符号的逐行恒等式；不同阶段换峰计数有重叠，不能把绝对贡献相加作为物理因果百分比。

例如固定波形移动一格时，T_(p+1)(y)−T_p(y)=y_(p+240)−y_(p+30)。因此，参考峰处 tail 修正为零并不保证动态峰窗口内 tail 不变；邻窗软惩罚也没有提供这种保证。

## 5. 复核与交付证据

保存波形复算精确重现全部 24 份指标 JSON、158,232 行 ADC/wave 原始字节和峰索引；响应 forward、QP、PCA 和新候选均为零。其原生墙钟 77.04 秒、峰 RSS 2.08 GB。原 preADC flags 由保存值保留，不从 ADC 逆推。

研究 API 的正式验证覆盖 CPU 旧028及 CUDA S/CLI，523 项黄金/重放张量检查全部逐字节相同；1,094 输出行、1,032 个 QP，实际墙钟 8.007278 秒、峰 RSS 4,762,599,424 B。三个保存示例本地重开共核验 143 数组。S 的 CPU 路径未在本次做完整黄金验证。[使用说明](API_GUIDE_CN.md)给出配置 SHA、环境与调用命令。

公开数学演示的最终运行只用一个合成事件、一个 QP，参考面积残差 8.12×10⁻¹⁸ V ns，线性误差 2.17×10⁻¹⁹ V，协方差恒等残差 3.39×10⁻²¹ V²。初版演示把局部时间坐标传给了要求绝对载体坐标的映射入口；修正后坐标范围为 [110,175]，本次打包累计运行两个合成 QP，初版回执保留。原算子、神经接口和科学结果没有因此重跑。该演示检验算子数学实现；与实测响应是否匹配由上述科学结果判断。
