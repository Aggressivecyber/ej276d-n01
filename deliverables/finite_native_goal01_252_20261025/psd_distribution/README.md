# 252 PSD 分布曲线

比较同一冻结FIT口径下的REAL、原模型M0和252唯一返回端点。主图为统一高斯带宽（h=0.009225）的概率密度及相对REAL的经验累计分布差；完整ECDF单列显示全部范围。全部样本参与密度归一化和累计概率，未裁掉负PSD或其他尾部样本。模型的103440条观察来自6465个父事件各2库×8次，不能视为103440个独立父事件。

PSD按原256点基线扣除窗口计算：总积分为[0,256)，尾积分为[46,256)，原q_floor=0.000531937891338保护保留。三组均无非正总积分、未定义PSD或PSD保护触发。这里绘制的是无条件一维PSD分布，不是电荷—PSD联合/条件评价。252的完整wave改善1.76686%，原研究未通过2%入口；本次仅绘图，新增拟合、端点选择、模型生成与随机draw均为0。
