## 一个固定候选

保留 BASE054 确定性均值 m、原 A0/M0/005、原 6593 SOURCE 和 21047 REAL、全部身份/权重/NaN/异常和统一原生读出。沿用 062 冻结的八个 log-Q 条件 SOURCE/REAL 正部 profile，不新增模板、强度或搜索网格。模板源于观测统计，不是已知的模拟前 ADC 真值；SOURCE/REAL 事件不配对，同数值 Q 不是能量真值。

在绝对样本 [110,176) 定义 p=argmax(m[112:144])，a=max(110,p-14)，b=175。用条件 profile 的梯形累计积分构造严格递增曲线；分别在 [a,p]、[p,b] 把目标累计分数反查源累计位置，获得单调的逆查询 t。固定 a、p、b 三个查询为其原位置，a 前保持恒等。查询只由输入 Q 和原确定性均值峰决定。

正部支撑 mask 为 m>0 且相对峰坐标>=2。P=mask*m，W 为上述查询上的分段线性电压插值加输出 mask，α=sum(P)/sum(WP)，新均值 m'=m+αWP-P。每事件只使用一个面积归一系数，不使用局部幅值雅可比。外支撑及原非正样本原样，正面积及 canonical Q 守恒。输入多个峰可保留，不能假定变为单峰；实际均值峰变化数和最终随机/ADC 峰都要报告。

原随机残差 r=M0-A0；R=mask*r，B=αWR，u=αWP/sum(P)。候选残差校正为 B-(sum(B)-sum(R))*u-R。固定均值条件下这是线性算子，逐次保持有符号面积；只有原条件期望为零时才保持该期望，不做样本居中。积分投影可能有负系数并改变条件协方差，完整条件统计必须检验。前缀、尾部、负部、原随机残差的外支撑均保留。
