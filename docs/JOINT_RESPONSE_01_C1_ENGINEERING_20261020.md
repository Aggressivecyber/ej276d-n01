# JOINT_RESPONSE_01: prospective C1 interpolation engineering contrast

The original sampled generator uses piecewise linear interpolation. At its exact M0 identity grid, the slope with respect to a time query can change across a sample node. Earlier saved full-signal attribution showed that generator approximation contributed materially to native-wave prediction errors. The fixed-bank/projection crossing now distinguishes the risk changes associated with sample banks and projections. These findings motivate one isolated interpolation contrast, not a further REAL fitting run.

The alternative `JointResponse01C1` inherits the exact original coordinates, 54 neural parameters, 46 physical-comparator parameters, bounds, conditions, latent sharing, M0 modes and electronics. It changes only interpolation between the existing 384 samples to uniform-grid PCHIP. The original implementation and all its results remain immutable. PCHIP preserves monotonicity on each interval and has a continuous first derivative in the interpolation coordinate; its second derivative need not be continuous. This does not make ADC, first-argmax, conditional binning or the complete parameter objective differentiable. It is an effective between-sample model assumption, with no claim of identifying a physical continuous waveform. See [SciPy's PchipInterpolator reference](https://docs.scipy.org/doc/scipy/reference/generated/scipy.interpolate.PchipInterpolator.html), including Fritsch and Butland (1984), DOI 10.1137/0905021.

## Frozen design and engineering trigger

First, compare original and C1 zero-coordinate outputs exactly on all 6593 SOURCE parents for both neural heads and the physical model, using zero latents and one fixed common random draw. The physical test sets all coordinates to zero; it does not claim its nonzero stochastic initialization is unchanged. There are 39558 full-row equality comparisons, with per-case hashes.

Then use only each original head's first FIT0 bank (1024 parents, four draws), first rejected trial0 and first accepted trial1 parameters from the completed multibank REAL pilot. Reconstruct each bank's original latent stream. For both interpolators at M0, build all 54 signal secant columns at the original 0.004 step, respecting the original one-sided noise bound. Combine all columns in each fixed joint direction. Compare the true generated signal to baseline plus the combined secants on all 4096 rows. No parameter direction is fitted, selected or committed.

Each of the four paired contrasts must reduce the signal linearization error, normalized by the common baseline Frobenius norm, by at least half; C1's normalized error must also be at most 1%. C1 movement norm must remain between 0.5 and 2 times the original movement, to avoid interpreting a nearly extinguished response as an improved predictor. Outputs must be finite, canonical signal charge positive on every row, queries strictly increasing within the original support, integer nodes exact, and observed interpolation overshoot at most 1e-12 V. Endpoint support arithmetic is checked within 1e-12 sample. These are prospective engineering triggers, not relaxed scientific success gates.

Save full baseline/actual signals, the two combined secant signals, first-eight-row finite-difference pairs and every C1 probe's full base, query and coordinate arrays. Independently recompute the errors and first-eight-row secant sums, and compare every saved C1 probe against SciPy PCHIP. Full-row errors use all rows; the eight-row subset only audits the sum construction. Exact M0 identity and an improved local predictor do not establish a correct conditional random kernel. Only if this contrast passes may renewed coupled teacher validation be registered; the changed generator cannot inherit the original stage-3 pass or proceed directly to REAL fitting. No heldout or REAL metric is evaluated here.
