## 2. 坐标与量纲必须跟着图表出现

模型内部载体为 384 点。生成信号加电子学噪声后只经过一次原 ADC，再减去原载体前 100 点均值，在 `[112,144)` 内取第一个最大值 p，输出 `[p−16,p+240)` 的 256 点。REAL 保留原规范 ADC；干净 SOURCE 不量化、不裁幅。时间步长为 1 ns，波形单位 V，Q/tail 单位 V ns，PSD 无量纲。

Q 对全部 256 点积分，tail 从输出第 46 点到末尾。输出峰固定在第 16 点是裁窗的构造结果，不能当作网络学会了峰位置。应报告原载体选中峰位置、搜索边界和全局峰在搜索域外的比例；主评价保存的 REAL 字段 `peak_index480` 是历史字段名，其数值坐标在此为原载体坐标。

基线噪声始终指裁窗以前的原 100 点 ADC 基线；输出 256 点的前 100 点包含脉冲，不能拿来代替该基线。长尾不作为无信号噪声真值。模型 canonical Q 的积分区间 `[110,366)` 与带噪声选峰后观测 Q 的积分窗可以不同，二者差异必须通过 crop migration 项呈现。

`PSD_raw = tail/Q` 保留符号，Q 恰好为零时未定义；数值评价的 PSD 使用已冻结 TRAIN `q_floor` 的带符号分母保护。Q≤0、PSD guard、raw PSD 未定义、ADC 碰轨及搜索边界都计数并保留父事件，不据此换核、换窗口或挑选行。

Window008 的 256 点数值不直接与旧 480 点 Q/PSD 距离做“提升百分比”。如将来需要横向比较，必须预先登记同一观测口径的重算任务，并单列新增执行。

## 5. 最小补充诊断设计：四项，等待独立登记与执行

以下是一个具体可实现方案；编号、预算和文件名需进入 addon manifest 后才成为执行协议。所有科学通过阈值仍为 null。各臂/各假设都保留，非有限值与工程合同破坏停止；搜索域边界或 Q/PSD 异常只报告。

### A. 固定 128 个 DEV SOURCE 父事件 ×64

用现有 `repeat_selection` 种子在 512 个 DEV SOURCE 身份中无放回选择 128 个，选择不使用生成结果或 REAL 数值；固定 parent-major 顺序。每个父事件使用 64 组响应、005 和 extension 随机量，使用现有 repeat 三个种子。三臂共享随机量，三个噪声假设共享005前缀、S和 extension epsilon。

保存原身份、全部64次 Q/PSD/raw PSD/time_scale/峰/crop migration/分解项及 flags。逐父事件报告均值、样本协方差（预登记 `ddof=1`）、Var(Q|x)、Var(PSD|x)、Cov(Q,PSD|x)；raw PSD 另报定义次数。另存256点均值和完整256×256样本协方差，包括逐父结果和跨父的概括；不把人口方差替代条件方差。

同步对纯 signal、同窗电子学、ADC residual 的 Q/tail 项求方差与协方差；这是观测分解，不是物理噪声源已被唯一分离。报告原100基线的 RMS、lag0–99 ACF、固定频带功率份额以及 S 分布，沿用已定义的005统计口径。输出噪声随假设的变化单列。

时间形态建议采用一个冻结、可复算的纯描述定义：在256点波形上以输出峰值的10%、50%、90%为阈值，从选中峰向两侧找最近阈值穿越并做线性插值，计算 rise10–90 和 FWHM；缺少穿越、峰非正等返回未定义并计数，不能删除整个父事件。原输出峰恒为16，载体峰和模型 time_scale 同时保存。归一化波形用各行正的观测 Q 归一；Q≤q_floor不定义归一曲线但保留原始统计与计数，不能把它称为全人口无条件结果。

64次的条件协方差只是本模型在这些随机假设下的有限抽样结果。没有同一物理事件的重复 REAL 真值，不得声称逐输入条件方差已唯一识别。

### B. 固定随机量、保持 Q 的形状替换

使用A中固定选择顺序的前32个父事件，不根据波形或评价结果再选。对每个父事件 i，在其余 DEV SOURCE 中按原 SOURCE `abs(log(Qj/Qi))` 选最近的非自身 donor j；并列按已绑定原身份稳定破平，不用生成结果筛 donor。保存实际 Q 间隔和原始形状差异，即使两个形状很接近也不另挑；零干预强度不能解读为网络忽略输入。

将 donor 的基线中心化384点float64载体按 `Qi/Qj` 缩放，保持原峰锚点126；原形状与替换形状都具有同一个 `[110,366)` canonical Q=Qi。对二者使用完全相同的8组 intervention 随机量，遍历三臂、三假设。保存逐 draw 成对变化、8次均值差和成对变化的Monte Carlo标准误、Q/tail/PSD、time_scale、rise/FWHM、均值波形差和归一形状差；随机重复之间的差异不能代替输入替换差异。8次均值的精度有限，不能当作精确条件期望。

单独做工程不变性：改写仅用于保存的父身份、打乱存储顺序时，按原身份重新配对同一显式 latent，数值响应应复现。批量处理可能有设备浮点差异，应记录最大误差与既定工程容差；不能通过重新抽随机数判断不变性。总体打乱后分布相似既不证明忽略输入，也不证明输入依赖充分。

### C. 同形状 Q 趋势

对B中的32个干净 SOURCE 形状分别缩放到已冻结 SOURCE TRAIN Q8边界中的25%、50%、75%三个电荷节点，保持峰锚点与归一形状不变。节点直接取已保存边界的第2、4、6个内部索引（完整9边界数组的索引2/4/6），不从 DEV 或结果重新拟合，也不裁切输入电压。

同一父形状的三个节点共享8组显式随机量，所有臂/假设共享；B/C可以复用一次由三个intervention种子生成并保存hash的32×8显式latent库，不能在各变体之间额外推进随机数。报告 qbar、qsig、最终 Q、PSD、tail、时间形态量及均值波形的节点曲线、相邻成对差异和实际缩放倍数。qbar 的结构单调性检查与带噪声观测 Q 的统计趋势分开。节点趋势是干预诊断，不是能量标定或物理非线性测量。

### D. 固定人口重权重

直接重用主评价全人口四 draw 输出，无新增响应前向。由每个 SOURCE 父事件的固定 SOURCE TRAIN Q8 bin b 定义 `z=(2*b−7)/7`，预先固定三套正权重 `w0=1`、`w+=1+0.5*z`、`w−=1−0.5*z`，再各自归一到父事件权重和等于父事件数。每个父事件四 draw 同权重；所有父事件保留。

TRAIN和DEV分别报告权重范围、ESS、各bin权重和、加权Q/PSD人口统计和条件统计、波形均值/方差、三假设敏感性及 full 对照差异。固定模型文件和状态 hash 必须保持不变；若使用响应输出时不再提供人口变量，相同 x/z 的响应不受外部重权重影响属于接口性质，应据实说明。

不根据 REAL 拟合权重，不更新人口模型，不把加权后更接近 REAL 当作响应已改善。该方案只测试温和的源 Q 人口倾斜；未核实 h 元数据物理含义前，不据此宣称粒子组成重配或对应采集条件。

### 前向与存储预算

A 需要每臂8,192次信号行前向，共24,576；B 原始＋替换需要每臂512，共1,536；C 三节点需要每臂768，共2,304。三项合计 **28,416 信号行前向、85,248 个臂×假设观测行**，每个生成行最多128的固定chunk；D新增前向0。身份／顺序工程重放另登记其实际重复前向行数，不混入这三个主诊断预算。这些都是拟定预算，不是执行计数，也不是实测耗时。

A 的完整原始256点重复波形约144 MiB，全部逐父256×256协方差约576 MiB（float64、3臂×3假设×128父），两者约720 MiB未压缩。B/C以成对scalar、均值/方差曲线及固定少量示例为主，不保存每个384点中间张量；存储与协方差可分臂/父事件流式计算。实际RSS/GPU峰值和墙钟时间须由人工shape一致的工程测试确认，不能拿训练速度估计为已测预算。继续沿用10 GiB GPU、8 GiB进程树RSS、3 GiB输出与独立监督器边界，若需改变资源必须先登记。

## 6. 独立 C2ST 的最小额外成本和限制

主评价的 C2ST 更新数仍然为0。若根流程决定补原提案的独立域分类器，建议单独登记一个最小任务：仅 `full256` 电压视图，9个臂×假设比较加1个 REAL B/A 对照，共10个独立小CNN；每个固定200步、每步每类64行，合计 **2,000分类器优化器更新、256,000分类器训练样本呈现**。响应/噪声/人口更新仍为0。可参考旧007独立CNN的8/16/32通道结构，但256坐标和新源码必须重新冻结，不能直接调用旧480视图切片。

输入可复用主评价已保存的 TRAIN2,048/类、DEV256/类匹配波形与身份，无需新增响应生成。分类器只在TRAIN拟合归一化和权重，固定最后一步测试一次DEV，不用DEV早停、挑seed、换架构、翻转AUC方向，也不用训练判别器。每个分类器都保留checkpoint、训练更新计数、test logits/labels和原身份；REAL/REAL为同一组内A/B随机对照。

同一个冻结分类器必须分别报告原人口AUC与Q8条件比较。一个明确的低成本口径是：在固定REAL TRAIN Q8内报告各bin的AUC，再按预登记的TRAIN共同支持bin权重汇总；计算规则、bin支持和缺失规则在看DEV之前冻结。若DEV某个正参考权重bin缺任一类，该汇总未定义并保留缺口，不临时重新归一成一个较好分数。仅Q8匹配仍不保证能谱细结构或粒子组成相同，不能称为完整物理条件可比。raw和条件视图可共用test logits，不新增分类器优化器步数。

如果另外要求归一化256点分类器，需再加10个CNN和2,000步；不要在看到full256结果后临时添加有利视图。100点基线因各臂/假设共享，可作为独立小任务说明重复关系，不能冒充9项独立噪声证据。

旧代码能提供架构和固定预算参考，不能提供本次实际GPU耗时、峰值内存或可分辨性结果。2,000步是明确新增计算成本，时间必须人工shape基准测试后登记。父事件/REAL软件组bootstrap不等于独立采集不确定性；低AUC不证明响应正确，高AUC也不能未经条件比较归因于响应网络失败。缺少这项时最终报告明确写“独立C2ST未执行”，不能自动当作通过。

## 7. 最终结论允许达到的边界

可以报告：固定256点口径下的分布差异、条件宽度、给定三个电子学假设的敏感性、输入替换的数值响应、模型的条件随机变化及人口倾斜的影响；每条都指向实际运行产物。

不能仅凭这些内部检查报告：电子学长窗已由100点唯一识别；某个假设代表真实硬件；逐输入随机响应被物理唯一识别；单次采集的人工分组建立了跨采集泛化；源人口差异已与探测器响应完全分离。

最终报告保留未通过、未支持、未定义和未执行项。新的科学结论必须同时说明支持它的实际证据和仍然缺少的采集／配对约束。
