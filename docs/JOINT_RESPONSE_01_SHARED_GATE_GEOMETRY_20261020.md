# JOINT_RESPONSE_01：已保存矩阵上的共同改善可行性

2026-10-20 前瞻登记，先用现有矩阵区分目标方向与原生执行误差。四轨迹比较已完成，两神经头分别接受 5/4 次更新，均失败 24/96 个最终改善门。63 个神经候选中，22 个满足全部四批 joint 接受却被 native 拒绝；相同 FIT 上 wave 的实际相对变化与线性预测之差最大约 4.25%/7.24%。现有求解器保持 joint 目标，native 只要求预测非增。原生分布距离、生成器插值及硬读出都可能产生非线性；这次不把其中一项预先定为唯一原因。

固定两个头在原三 FIT 第 1 方向、M0 零增量中心的第二次试探矩阵与半径 0.00625。这两次原试探均被接受，故可在相同已暴露 FIT、同一割线校正矩阵和半径上比较目标设计，避免改模型、换批或继续扫描尺度。两原候选与其结果原样保留。只读取已保存数组，不生成波形，不提交更新，不读取 CHECK/FRESH/FINAL 选择新设置。

每头只解一次 54 个单位化位移加一个共同进度 gamma 的凸约束问题。最大化 gamma，范围 0 到 1。9 个 FIT/噪声假设视图各要求预测 joint 风险至多为当前的 1−0.20gamma，peak-code 宏块风险至多 1−0.10gamma；18 个 native wave/QPSD 标量至多 1−0.05gamma。9 个 noise 线性预测仍不增，原 36 个宏块界、原参数边界与球形半径保持。这里的 20%/10%/5%来自既有科学目标；矩阵预测不能替代原 hard 检查或最终新库门。

gamma 至少 0.10 表示局部模型可同时预测目标改善的十分之一，即 joint 2%、peak 1%、native 0.5%。仅当两头都达到该预设诊断要求，才支持另行登记原生固定候选确认；否则先记录哪类约束限制共同改善。该数值是下一小诊断的触发条件，不修改原科学门，不将预测判为响应成功，也不直接训练。

新增预算仅 2 次 CPU 求解，最多每次 300 次 SLSQP 迭代，ftol 1e-10。解析约束梯度用固定零点、55 坐标的中心差分核验，共 220 次小矩阵约束函数计算；不调用模型或重新计算数据 Jacobian。4 CPU、GPU 0、RSS 上限 4GiB、内部 120 秒、外部 150 秒、输出 32MiB，无自动重启。完整保存输入矩阵、解、边界、预测、slack、求解器状态和计数，独立复算后决定下一步。此为短步骤，立即执行，不设置定时。
