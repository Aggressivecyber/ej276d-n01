# 060：固定BASE054与REAL的完整条件波形统计

059已核验闭合。宽度差距主要处于均值和电荷箱间关系；低Q误差主要在峰后，高Q两侧均不足。052/053证明仅按交点放大时间变形会恶化完整波形，059的标量CDF不能唯一给出可用的完整波形修正。既有归档只有总体256点profile，没有逐Q的完整形状与协方差。本次仅提取这一缺失证据，作为下一均值表示的设计输入。

## 必须新增的统计

1. 每个波形人口均保留全部256点均值、总体SD和SD/sqrt(n)，前64点的完整协方差，以及16个不重叠16点积分的均值与协方差。使用总体分母n，不把此处描述性SE当作独立采集置信区间。前64点覆盖峰前、峰和首段尾部；后192点仍有完整逐点均值/SD及块协方差，不宣称保存了其完整逐样点协方差。
2. 两种视图同时统计：原电压V，及wave/(sign(Q)*max(abs(Q),原q_floor))。Q=0按既有正号保护分母。保持所有行，明确记录Q_nonpositive及Q_guarded数量；归一视图是描述性形状，不反演ADC。
3. SOURCE两种固定分组：原A0输入Q八分位组；对应BASE原生输出Q组。fast五阶段与自身均值使用同一fast BASE原生Q成员；slow/common原生使用其各自Q成员。REAL只用自身原输出Q八箱。不按结果重新拟合边界或删箱。每组n<2立即失败，禁止补默认统计。
4. 每人口按既有父行/REAL行的奇偶分成两份，仅保留各组两半的行数与256点均值，检查描述性稳定性。它们不是独立采集、确认库、DEV或新的科学接受门槛；不选择更有利的一半。
5. SOURCE人口共16份：每头fast五阶段5份（原固定BASE锚点的均值、M0随机、电子学、ADC，以及原生重选峰）、自身均值峰下1份、slow/common原生各1份。加REAL1份，共17 profile记录。全量阶段仍仅fast，不据结果选H。
6. fast每头另保存同父五阶段有序分量（第一项为均值，其余为相邻阶段差）的256点均值及5×5逐点协方差，按上述两组各八箱；核对相加后的均值、方差等于最后原生阶段。只对原V视图分解，不把依赖阶段顺序的协方差当作唯一物理归因。
7. 原059的BASE全量几何、原生特征、fast五阶段特征/交点、内在均值及前32例继续保存，用于精确重放和profile的线性量核对。原始全人口完整波形不导出；聚合profile的离线核验范围是计数、分组/分半重建、矩闭合及与已有Q/tail/peak特征的关系，不能宣称离线逐样点重新读取了全部未保存波形。
