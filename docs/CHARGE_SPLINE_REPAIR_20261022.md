旧模型将 logQ 和 log 幅度送入高自由度条件 MLP/FiLM；此前固定这两个输入的因果实验已消除两组主要输入形状的波浪。作业168的有限方向搜索没有接受更新，最终模型未改变。此次更换产生问题的条件路径，原模型、历史失败和预算均保留。

## 实现与初始化

- 冻结原 U-Net，保留连续的归一化输入波形与原探测器条件，只将残差支路的 logQ/log 幅度输入固定为零。
- 保留冻结的原单通道均值头，加上六个零初始化的卷积系数头；使用 logQ 上的三次 B 样条加权后加入原头的 logits，再经过原 tanh、门函数和电荷归一化。
- 样条范围仅由 SOURCE FIT 确定，两个内部结点位于三等分处。全波形曲率约束仍作用于两个既定形状原型的128点 logQ 网格。没有强制 PSD 恒定或单调。
- 冻结时间映射、电荷映射、M0 波形基和电子学坐标。训练966个样条参数及原有53个联合响应坐标，共1019个参数；事件 ID 只索引缓存。
- CPU/GPU 合成检查通过初始化等价、Q/幅度隔离、输入形状影响、电荷守恒、曲率梯度和重复父事件的精确伴随回传。GPU 初始化误差为1.39e-17 V，伴随最大绝对误差为2.98e-8。

## 固定实验

保留6465个 SOURCE FIT 父事件和18948个 REAL FIT 事件。REPORT 不参与训练、归一化或设置选择。固定24步 Adam，每步两组独立的每父事件8次随机采样；完整分布记忆损失与全波形曲率共同训练，固定参考的条件波形超限惩罚及 ADC 边界风险参与目标。统计约束可以在恢复训练的中间状态违反，最终候选必须通过原联合验收；训练更新不等于科学接受。

终点使用两组每父事件32次采样，对比原模型、继承模型、固定条件起点和固定第24步候选；不选择最佳步。原计划要求终点随机种子与训练独立，但事后核对发现 seed 与第21步重合，独立性要求未实现，见后述审计。保持 PSD 至少改善10%、Q/整体波形/峰位置误差不劣于原模型2%、支持的92个条件波形单元不劣于继承模型2%、Q-wave 改善、异常标志不增加，以及两组曲率和波浪过量变化均至少减半的验收标准。FIT 全部通过后才进入固定 REPORT 评价。
