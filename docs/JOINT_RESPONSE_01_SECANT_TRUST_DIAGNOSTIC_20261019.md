## 证据和要检验的改变

生成器/指标归因在25.31秒正常完成，640源码及12输出哈希通过。全行信号误差、319488行独立NumPy硬读出、全部24/36个joint/native分解通过独立审核。四个较大联合步的信号近似误差为实际信号变化的37.7%–54.6%；12个原硬读出wave比较中，生成信号近似造成的指标差都大于剩余读出/指标项。小位移仍受读出离散性影响，不能宣称只缩小差分尺度便已修复。

原生成器、54个参数及边界、完整硬读出、联合特征、原生指标、人口和科学门完全不改。只检验联合局部近似：先用已有FIT实际探针给完整joint/native矩阵作秩一割线校正，再在较小信赖域内重解全部参数的组合方向。保留原完整J转置J交叉项；不逐坐标通过后冻结。

设固定中心残差为r，保存方向位移为s，其实际残差为r_s，矩阵校正为 `J_new = J + (r_s - r - J@s) s.T / (s.T@s)`，native矩阵作同样校正。每次校正检查割线恒等式。它是在有限尺度拟合观测变化，不称硬风险的无偏导数。

## 固定输入与算法

FIT精确复用读出归因的端点、1024父×4draw、4096REAL、随机库和特征2026101942；原native上下文也保留。使用原0.004差分矩阵，初始校正仅取已保存的1/32探针。这个拟合信息已经暴露，明确作为方法开发数据。

初始参数信赖半径0.0125，即此前0.4方向的1/32长度；该位置原wave预测误差在所检验两种子和三假设下低于1%。它是本次有界数值设计，不是物理参数精度。每种子设置一个“只缩小半径、原矩阵不校正”的首步对照；该对照仅一候选，用于区分首次方向的变化，不构成等预算优化优劣比较，也不参与校正矩阵。

主校正支路每种子最多8次：使用原native约束求解器、ridge0.02、maxiter200、ftol1e-9在当前半径求联合方向。候选经FIT和CHECK真实硬读出接受。失败后只用FIT实际误差进行下一次秩一校正，半径乘0.5，再重解方向；CHECK数值不进入校正矩阵。首个FIT/CHECK通过后停止并只检验一次FRESH；FRESH失败不继续找候选。零方向结束该支路并保留原因。中心参数始终不变，所有候选只保存为未提交参数。

CHECK/FRESH均从已有拟合角色抽取，SOURCE/REAL抽样seed偏移100/200，bank偏移1000；CHECK基种子3200000、FRESH3400000，第二神经头统一加100000。特征投影CHECK2026101980、FRESH2026101981；native检查投影CHECK2026101982、FRESH2026101983。两支路共用同一批和库。新投影只用于检查，不回填FIT方向。A0/M0/005/PCA与尺度仍来自全TRAIN，所以这是冻结系统上的方法检查，不是全流程未见验证。报告留出、DEV、C2ST都不用。

FIT/CHECK/FRESH均使用原联合接受函数：joint至少1%改善、宏块1.15和有限样本余项、原输出信赖域/flag守门。native wave/QPSD≤1.01、noise≤1.10，同时对照本轮中心和固定M0起点；原M0锚定不可因中心已有退化而移除。宏块和native都按三噪声假设报告。

记录原J/nativeJ、初始校正位移和实际向量、每次求解前矩阵、proposal、完整FIT/CHECK/FRESH实际残差及native向量、预测向量、原始风险/信赖域/flag计数、求解几何、每次半径、拒绝和停止理由。独立重算所有割线校正、矩阵预测、原接受门与FRESH判定。不能用运行完成或局部1%保护代替原20%joint、10%peak、5%native等最终科学改善要求。

两种子主支路FRESH均通过只表示方法进入下一项前瞻训练设计的局部条件成立；不自动训练，不选某种子或投影为最终成功端点。首步对照若已取得同样证据，应优先评估更简单的半径修正是否足够。失败保留原值，不放宽门、不加候选、不自动重启，不因此扩大网络或修改硬读出。
