# JOINT_RESPONSE_01：原生成器32draw三轮REAL校准

2026-10-20前瞻登记。原生成器FIX01的两头108差分列、3联合解和3候选已经独立复算，两个头均通过原FIT/CHECK/FRESH局部门；FRESH联合风险剩余0.918138/0.967731，native wave最差为1.008556 M0。旧4draw候选在同32draw FRESH上也通过，因此本次证据仅支持有界循环方法试验，不能认定32draw是唯一可行精度或已满足最终响应门。

## 目的、初值与停止规则

采用原JointResponse01及两个原M0头，从M0零增量重新开始；物理比较从原46参数物理初值重新开始。两神经54参数与两物理46参数轨迹各固定3个外层方向，每方向三FIT批。三轮是每轨迹完整覆盖6465 SOURCE拟合父和18948 REAL拟合行所需的最少整轮数：每轮访问3072父，二轮仅6144；三轮9216父和36864 REAL行。完整排列依次消费，跨排列边界自然重复保留。

这不是旧12轮运行的续跑，不导入任何未提交诊断候选。三轮预算在新结果产生前冻结；报告角色不选择端点，不因未达门追加轮数。每方向至多3候选，首个全部FIT/CHECK通过者提交一次联合更新；零方向结束当前外层方向，其他求解错误立即终止。全部旧科学失败与资源终止记录保持。

## 唯一方法变化与资源实现

每个FIT/CHECK批由1024父×4draw改为1024父×32draw；REAL仍4096原始行。每批32draw使用新独立随机流，不继承上一诊断的4draw。原同一完整生成表达式、噪声、硬读出、分箱支持、联合特征定义、差分0.004、ridge0.02、初始半径0.0125、拒绝半径减半、三批完整J转置J及27个native非增约束保持。

保留每批至少1%联合改善、宏块1.15+2/4096、相对RMS均值0.08/p99 0.25、flag增量max(4,0.005×32768)。native wave/QPSD≤1.01、noise≤1.10同时相对当前端点和固定初值核验，避免逐步退化累积。仅拒绝候选的FIT完整残差用于割线修正，CHECK不回填。

32draw随机库和基准carrier保存在CPU，每次只有当前完整库与观察量驻留GPU；复用已通过的FIX01 prediction/hard_check/native_values函数。等权8:1 W1使用已核验的精确次序统计量实现，其余样本比例和带权路径保持。原模型、loss、观察和原拟合驱动文件不修改；新驱动仅改变上述存储方式并调用已有内存受控函数，原evaluate/decide/kernel_control原样复用。
