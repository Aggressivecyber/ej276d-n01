# 007有限阶段的核验范围

本文件在4000步阶段末点产生前记录，由主代理自行核验；没有子智能体，也不称第二方独立审核。

训练实现复查确认：两臂共同部分使用相同初始化、采样器及显式随机流；100点噪声005及480点条件延拓均冻结。每一假设分别算损失后等权平均，三个训练判别器独立更新。候选ADC只作用于信号与该假设噪声的和，保留各自饱和梯度；不把三条候选波形平均后训练。信号网络不接收假设编号、父ID或人口标签。噪声基线项在本阶段不可训练，完整随机臂的信号随机头只在联合阶段解冻。

训练末点应满足两臂各4000 G、每假设1000 D（合计6000 D）；确定性臂日志首行必须与已保存的历史第1步完全相同。原先的1次科学更新计入累计8000，新增为7999，人工工程测试不计入科学预算。保存的共同3000步参数与逐步损失将作逐位配对核对，最终随机流及父采样器状态应一致。完整臂的随机分支必须有已记录的非零梯度，不能以结构存在代替实际训练。

先在本地CPU检查源SHA、全部完成文件SHA、日志顺序、阶段、实际G/D计数、覆盖、冻结噪声、正Q与PSD保护标志；从已保存观测值重新计算各分箱Q/PSD均值、SD、IQR和敏感性点值，并由保存的1000次bootstrap值重算区间。对保存的样例独立计算整数ADC码（零差）、规范电压浮点误差、Q和PSD。

若截止前时间充足，在训练退出后使用同一冻结末点、原TRAIN父、已登记随机流与种子重放全部生成诊断。该步骤不训练、不加新样本或新随机抽样、不解码DEV；单独记录工程重放行数与原生退出。它验证可重现性，并非对同一实现的科学正确性作独立证明。若没有执行或没有通过，必须明确保留该限制。

报告同时列出三假设和最差假设的等样本wave/QPSD/noise距离以及REAL-REAL对照。完整原人口摘要与group平衡2048距离分开解释。两臂自身固定signal-Q箱的父人口可能不同，所以宽度敏感性比值不能直接用作臂优劣排名；输出Q箱与原SOURCE-Q箱摘要均保留。训练集结果不等于DEV泛化、跨采集验证、物理噪声识别，也不完成原每臂19000步末点。
