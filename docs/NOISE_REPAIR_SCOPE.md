# 诊断后的修复边界

本文件记录用户 2026-10-12 新审查后的实现方向；不是新的训练启动回执。run_001 的模型、数据、损失与结果仍封存。本轮新增程序均为冻结模型诊断或人工检查。

下一候选保留 N01 U-Net、电荷头和物理随机头，只单独实现“平稳相关电子学噪声＋事件基线偏置”。电子学 FIR 使用自由系数和 L2 归一化，将滤波形状与噪声幅度分开；单位脉冲仅作初始化。首个候选不含逐事件随机斜率，不将短窗 OLS 截距/斜率的标准差或 0.95 相关系数直接复制成潜变量参数。幅度变化和偏置分布应与完整基线联合拟合。

这项限制只适用于电子学候选，不能对最终波形投影电荷，也不能将“关掉斜率的旧输出”当作已训练修复模型。前100点不足以证明480点尺度上的慢漂移不存在；若后续恢复随机斜率，需显式区分潜在漂移协方差与相关噪声导致的 OLS 估计协方差。

新噪声拟合必须先独立登记数据角色、随机流、固定预算、末端规则和停止条件。评价至少覆盖完整100点联合结构、基线均值散布、每事件RMS、ACF、频谱、OLS联合统计，以及父/组隔离、样本数一致的独立域分类器和组内随机标签 REAL–REAL 阴性对照。原验证集已经用于机制诊断，后续报告须说明这个复用事实；不能重新称为从未查看的独立终验集。未通过噪声验证便停止，不进入脉冲训练。

在同一已验证的电子学候选上，只重做确定性与完整随机响应的必要比较，先使用统一计数比较权重。修正分布目标时：训练方向按更新刷新并在一次双遍计算中原样复用；评价采用独立冻结方向库，并补充逐坐标和短延迟联合结构。固定投影数量不应仅机械扩大；也不能把新增统计的数值下降自动等同于完整响应校准。

本轮未训练新的噪声候选，亦未启动两组波形重训。实测组来自同次采集，物理权重、独立采集验证与绝对硬件校准的未知状态不变。
