## 3. 优先厘清的三种机制

**第一，提出方向的目标与接纳目标并不相同。** FIT 最小化三个 H 的平均 energy，data 为六个 wave 视图的平均 energy 加两倍 integral energy，再加小正则项；CHECK 要求每个 H 的 data 与 wave 都通过原下降/非劣规则，同时守住 native W1、PSD 和异常指标。即使观察链可微、梯度精确，平均目标下降也不保证每个目标同时下降。现有记录证明这种目标取舍实际出现过，但尚未证明不存在共同可行的下降方向。当前运行继续使用原协议；后续若修方向构造，应让它面对原约束，不以降低接纳要求替代。

**第二，硬观察的有限变化与反向传播方向需要分别判断。** 当前 hard 与 STE 的 ADC 前向数值相同；STE 在 ADC 范围内用恒等反传，范围外按 clamp 截断。硬量化本身是分段常数。选峰和裁窗索引没有梯度，gather 只向已选中的样本传梯度。候选可能改变峰索引、裁窗、观测 Q/PSD 或未定义计数，而反传并未描述索引跳变。日志没有同库、同方向的代理导数与有限硬变化对照，**不能据此宣布 STE 是根因，或宣布全部梯度错误**。

**第三，当前均值族的自由度有明确限制。** `model038` 是固定 A0 上的条件化时间重参数化，而不是任意波形修正：

- 条件只有固定 SOURCE 的 log canonical Q 与原 013 PC1；共享网络 `2→16→8`，184 个均值参数。
- 时间锚点为 100、126、383；前段 3 个、尾段 5 个自由区间 log 增量，经正值归一形成单调分段线性查询。
- canonical Q 是固定 `110:366` 求和，不是全部 384 点面积。变形后用 `Q(A0)/Q(warped)` 归一，要求比例至少 0.25，增益最多 4。前 100 点保持原值。
- 均值阶段没有独立垂直残差、自由电荷增益、新 local 噪声或新随机协方差；原 M0 随机头冻结。固定 canonical 均值 Q 不保证硬 ADC、噪声和动态 256 裁窗后的 observed Q 不变。

由当前模型可直接推得一个局部关系。对恒等时间映射附近的位移 `u(t)`，记 `Q0=Q(A0)`，在可微区间内：

\[
\delta m(t)=A'_0(t)u(t)-\frac{A_0(t)}{Q_0}\,Q[A'_0u].
\]

这是代码结构的局部推导，不是文献对本项目的验证。它表示修正主要沿原波形斜率作用，并伴随一个保持固定 Q 的整体增益补偿；平坦区域没有任意独立的局部垂直自由度。每事件最多 8 个局部时间方向，实际共享 conditioner 又耦合了不同事件。分段插值节点只能按相应单侧/分段导数理解；局部线性空间不等于完整非线性可达集合。拒绝了 6 个优化方向，远不足以证明整个波形族不能表达 REAL。

| 两个 REAL 端点均支持稳定且有用的形态改善，随机模块有额外收益 | 完成统一证据与限制报告，保留当前候选；不为增加实验数量再开诊断 |

| 大多是 native 通过、硬变化未分辨 | 报告精度不足；只在后续有限预算设计中考虑方向/估计精度配比，不把 CHECK 无限加倍 |

这是按完整证据作出的分支顺序，不同时启动多种路线。当前 24 候选只是用于提高归因质量，不能替代完整终点。

## 6. 最小波形族拟合应如何落地

建议的唯一下一项科学设计是**有条件触发的观测域波形族拟合**，用来回答“在已记录的合法 REAL TRAIN 窗口里，受限时间变形能描述哪些形态、还剩哪些稳定残差”。本页没有把尚未绑定的模板、坐标映射和求解次数伪装成可启动配置。

1. **拟合对象。** 使用原合法 REAL TRAIN 及原记录组、原权重。任何按可定义观测量形成的显示分层都保留全人口分母；Q 非正、rise 未定义、截尾和碰轨记录单列而非删掉。只拟合实际记录的窗口，不把由 256 点外推的 384 点当真值。不用 SOURCE/REAL 最近邻、同 Q 箱或伪标签制造事件配对。单事件残差混合了涨落、电子学噪声、量化和裁窗效应，不是已知的纯条件均值残差；观测 Q 归一也不等于 038 的 canonical Q 守恒。
2. **模板与自由度。** 首先明确模板来自已有哪一合法参考，时间坐标如何对应实际窗口；模板只能由指定的 TRAIN 拟合组确定，并在比较变形拟合之前固定。逐事件自由参数与跨事件共享参数分别列明；不能逐事件把目标波形本身当可调模板，使低残差变成自重建恒等式。拟合比较保持相同模板、归一口径与自由度约束；不同时增加可学习人口、噪声模型或全局电荷校准。若采用 REAL-only 模板，它回答的是观测形态重建问题，并不等价于当前 `A0(x)` 的条件网络可达性。
3. **保留一个受限问题。** 使用与当前时间变形结构对应的前沿/尾部正增量及固定锚约束；若实际观测坐标不能支持这些锚，先明确几何映射及其假设，不能硬套。模板、锚、零电荷/幅度定义、损失权重和最多拟合次数在计算前一次绑定。后续若比较平滑残差，必须先给出时间族拟合残差证据，再冻结最小残差支持域与自由度，不能从看过的 DEV 自由设计。
4. **判定与停止。** 输出原人口下的重建误差分布、前沿/峰/尾/宽度与积分残差、异常和未定义分母，以及组间残差方向的一致性。若用内部组拆分，它只检验该描述拟合的组间稳定性；A、005 未全流程重拟合时，不能称端到端未见验证。达到事前求解上限或未得到可复现的残差即停止，不扩大网络/LR/初始化搜索。
5. **结论强度。** 找到低残差解可证明所定义模板族存在一个好的拟合实例；有限优化找到的可行残差通常是最优残差的上界。残差大或不收敛，只说明该求解预算未找到所需解。若给局部切空间的残差投影，应写明只在该线性子空间内的结果，不能当完整非线性族的不可表达性下界。观测噪声和人口混合仍可能形成残差；不可把残差自动归因于探测器硬件。描述拟合成功不证明共享条件核能学到该解，拟合失败也不自动支持添加生产模型残差分支。

启动前需要从当前完整输出绑定的量只有：模板/实际坐标与覆盖定义、残差位置及物理单位、有限求解与读出预算、对应的停止规则。这些属于实现规格，不增设逐步人工确认；由根层在同一 038 工单中形成具体设计，Sol Max 实施和独审。本页仅完成规划，未登记或启动新的拟合；既有整体授权持续有效。

本次调研的交付成功标准是：拒绝原因可追溯到保存记录；论文与本项目的推论明确分开；后续动作由完整 038 结果触发；不为等待时间制造额外科学计算。实际训练、端点评价和科学接受仍分别记账。
