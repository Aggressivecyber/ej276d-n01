# 003 前瞻补充：固定数值与固定位置的配对分支

在任何新原始行解码或分类器拟合前补充以下分析定义；不扩大样本范围、输出上限或计算预算。

同时记录降采样量化前的 CFD 位置和实际量化/float32 后的 CFD 位置。比较 `align(pre_ADC, actual_shift)` 与 `align(post_ADC, actual_shift)`，固定裁窗位置以隔离数值量化；比较 `align(pre_ADC, pre_ADC_shift)` 与 `align(pre_ADC, actual_shift)`，固定数值以观察 CFD 位置选择。任何越界分支显式记为不可用，不把填充值当纯噪声或静默丢行。

本轮仅观察既有合法 TRAIN 事件；其波形 QC、触发和历史选择的因果效应不可从这批已入选事件单独识别，记 `selection_effect_identified=false`。若异常在原始 NPZ 中已存在，结论只到“早于本轮追溯的降采样和对齐处理”，不能进一步归因为硬件、特定漂移或某个未知上游操作。

跨阶段的分解指标与全部配对分支一起报告，不按结果选择最有利的一支。

分类器每次组内拟合分配种子为 `split_seed_base+i`，测试分配种子为 `split_seed_base+128+i`（i=0,…,127），从预先固定的不同组集合取样。拟合与测试使用互不重叠的角色随机流；其余种子按主协议的 base+i。当前身份元数据确认全部 422 组各有 48–50 条合法 TRAIN，旧等额配额有足够容量；容量不符立即停止，不启动替代配额算法。
