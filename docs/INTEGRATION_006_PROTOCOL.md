## 冻结输入和三个延拓假设

005噪声末点、run001的两个stage_20000末点、run001的TRAIN统计、旧配置、005完成回执、数据容器和PARENT_IDENTITIES均在配置中绑定SHA256。旧源码保持原字节。只读读取005的学习结果，不重新估计其均值、协方差或尺度。

设005模型的`mu100,L100,eta`已冻结，`C=L100 L100^T`，`S=exp(eta*u-eta^2)`，`E[S^2]=1`，`x=mu100+S L100 z`。005原forward直接生成x，前100点逐样本原样保留。

全窗采用原N01软件坐标0..479，1点对应现有1ns处理网格；这不验证仪器原生采样周期。设`v=mean(diag(C))`、`d=abs(t-s)`，固定三个参考核：

1. `fast`: `v*exp(-d/4)`。
2. `slow`: `v*(0.75*exp(-d/4)+0.25*exp(-d/80))`。
3. `common_level`: `v*(0.75*exp(-d/4)+0.25)`。此项是共同基线水平，不是随机斜率。

所有全480点参考核统一加`1e-6*v*I`后再分块。用float64 Cholesky solves计算`A=K_TB K_BB^-1`、`R=K_TT-A K_BT`；R仅作对称化再Cholesky，不自适应加ridge、不裁剪特征值、不在失败后更换核。`mu0=mean(mu100)`，`mu_tail=mu0+A(mu100-mu0)`。

后380点为`tail=mu_tail+A(x-mu100)+S*chol(R)*epsilon`。epsilon独立于z、u和旧响应随机流；S必须与前100点共用，不能再次抽样或漏乘。真实联合协方差为`[[C,C A^T],[A C,A C A^T+R]]`，通常不是参考K。前缀非平稳，因此不能称整480点已拟合平稳噪声。有限假设族的覆盖不是长程相关性的置信集合。

条件高斯计算依据Rasmussen与Williams《Gaussian Processes for Machine Learning》第2章式2.23–2.24及第4章的协方差核闭包；书籍仅支持计算方法，不证明此处三个假设适合探测器：[第2章](https://gaussianprocess.org/gpml/chapters/RW2.pdf)、[第4章](https://gaussianprocess.org/gpml/chapters/RW4.pdf)。

## 信号分离、单次量化和同处理REAL

从旧模型同一次显式随机输入的返回分量直接计算`signal=qsig[:,None]*unit_shape+signal_noise`。不使用量化后waveform扣噪声，也不以`pre_adc-old_noise`作为候选信号。旧forward计算的legacy waveform独立保存作参考，不进入新候选链。每个新候选只计算`digitize(signal+extension_noise,ste=False)`；量化、饱和区间与原14位算子保持一致。另报告`digitize(signal)`这一无电子学参考，它不是可交付候选。

这两个旧响应是在旧噪声下训练的，可能补偿过旧噪声。替换噪声只定义冻结权重下的反事实敏感性，不是修复后的响应性能。两臂已经分别训练，容量也不同，本轮相对差异不等同于随机支路的架构因果效应。

每个父事件、draw、chunk的旧响应随机量、005随机量、epsilon在两臂及三情景之间配对复用；这不意味着两臂不同权重产生相同信号。三个独立CPU torch随机流以配置绑定的seed、固定128行chunk、parent-major顺序生成，均为显式float32标准正态，计算为原规定精度。保存初末RNG状态、每chunk随机量与输出hash，足以从同一输入重放。保存全部事件读出和有限波形样例，不公开REAL原始或降采样波形。

REAL只经过原canonical ADC预处理和与生成相同的确定性读出，不添加005噪声，不施加随机信号响应，不通过去噪宣称取得真信号。Q为`sum[100:400]-3*sum[:100]`；tail为`sum[150:400]-2.5*sum[:100]`；PSD使用旧固定q_floor及带符号分母保护。保护行、Q非正行、饱和全部计数，不静默丢弃。

必须量化记录旧signal前100点泄漏。严格保留的是noise前缀，不预先声称组装后前100点等于005噪声。加入信号后与纯噪声前100点的差及ADC格点变动比例单列。若最大绝对信号泄漏超过1个ADC step，则不能把该接口称为保留005观测基线，当前响应训练入口被阻止。

前缀检查分别核对噪声preADC与005逐位相同、噪声postADC与005逐位相同、组装响应postADC前100点跨三个情景相同。电子学Q不投影为零；验证`Q(signal+noise)=Q(signal)+Q(noise)`及原模型组装恒等式。

## 统计、分箱和配对不确定性

复用run001冻结TRAIN的q_reference、q_floor、peak_floor、7个charge_bin_boundaries。Q坐标复用原log(Q/Qref)/低Q C1-asinh定义，bucketize边界等于时归左，首尾保留溢出。两套分箱均报告：

- 首要敏感性分箱：每臂固定无电子学preADC signal的Q成员（不是量化后的signal_only），同父同draw跨三个情景不变；每箱至少32个独立SOURCE父和128行，低于此支持标为不足，不编造通过。
- 描述性分箱：按各情景最终输出Q重新归箱，与REAL同坐标分箱对照SD、IQR和均值，同时记录相对于固定成员的8×8迁移矩阵。混合箱宽度不是已识别中子/伽马分量的宽度。

保留每事件Q、tail、PSD、峰值/峰时/半高上升时、饱和/保护标记、parent ID/draw/bin；保存各臂各情景全480点均值/方差、固定箱均值/方差曲线，以及同父4draw聚合的within-parent方差。单父4draw仅3个自由度，不能作为精确单父波动验收。

对噪声本身直接输出解析全480均值/协方差、`VarQ=cQ^T Cov cQ`、`VarTail`、`Cov(Q,Tail)`，以及99→100增量的均值/方差、与前缀90..99相邻增量的比值、跨界相关、后段逐时方差。解析跨界方差为`(a100-e99)^T C(a100-e99)+R00`。没有事后taper或强行边界等值。

固定1000次SOURCE父级配对bootstrap：每次以原父为cluster重采、保留其4draw和全部情景，独立于全部生成流。同一重采同时用于两臂。报告下面跨情景Q/PSD均值范围和各固定箱PSD SD比的95% Monte Carlo区间；REAL TRAIN归一化尺度固定，不把该区间称为独立采集泛化不确定性。全部箱的最大比以同一bootstrap计算区间。SD为总体ddof0，IQR为linear quantile。无参数再拟合。

## 预先声明的决策

工程检查包括所有绑定未变、原数据角色和父覆盖、前缀bitwise相等、解析分块与正定、同S/随机流隔离、原信号组装恒等式、每候选单次ADC、有限输出、无静默删除，以及上述信号泄漏限制。边界增量与短窗粗糙度本身仅报告，不把有随机噪声的逐点增量强行视为不连续错误。

只有TRAIN参与下一阶段筛查，DEV不改变任何决定。以下是有限假设族中的实用稳定性容差，不是物理等价验收：

1. 每臂跨三情景Q均值范围 / REAL TRAIN Q标准差 ≤0.05。
2. 每臂跨三情景PSD均值范围 / REAL TRAIN PSD标准差 ≤0.05。
3. 两臂所有足支持固定箱的跨情景PSD SD最大/最小之比 ≤1.10；所有8箱都须有足够支持才能给出全范围通过。
4. 解析noise-only后段400:480逐点方差的均值，跨三情景最大/最小 ≤1.25。此量不混入源人口展宽或单父估计方差。
5. 两臂三种新候选中任何TRAIN输出Q非正或PSD分母保护，均优先映射为`interface_fail`，同时保留具体行及计数；legacy或signal_only的同类问题另外报告，不因legacy也有问题而豁免新候选。不能用保护后的有限值宣称响应有效。

点值与配对bootstrap共同解释：若任一bootstrap下界已超过对应容差，或解析第4项越界，记`sensitivity_detected`；若所有上界均在容差内且足支持，记`sensitivity_within_family`；若区间跨容差或支持不足，记`MC_inconclusive`。工程检查失败优先记`interface_fail`。本轮均不追加draw或重抽seed。旧full与deterministic相对REAL的差异及排序只作描述；本轮不重新宣称哪个响应模型合格。

`sensitivity_within_family`只允许下一份、另行冻结的假设明确的两臂响应协议；不自动把005或旧gate重标为通过。其他结果保留具体失败/敏感来源，停止本轮固定候选的正式响应训练，不选一个有利情景掩盖依赖。敏感性不是研究不可推进的证明；若后续继续，需要把假设依赖明确纳入训练比较或取得新的约束。当前零训练协议不预支38000次响应更新。
