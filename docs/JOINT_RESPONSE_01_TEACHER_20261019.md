# JOINT_RESPONSE_01：多耦合教师闭环登记

本阶段检查新的联合模型与优化器，不校准 REAL。阶段 2 已验证：两种 M0 的 6593×2 个零增量输出与三种硬读出精确一致；非零模型、物理比较器、同父核和 54 列有限差分均可执行。小批 128×2 的完整 Jacobian 约 0.84 秒，只能作为预算依据，不能证明可辨识性。

教师以两组原 M0 为各自基础，同时改变六个响应均值、Q/形态条件依赖、具有非零交叉项的 6×6 涨落矩阵、原八模态尺度和电子学尺度。详细参数由冻结源码 `teacher_parameters` 给出。恢复优化器从 M0 零增量起步，不接收教师参数、逐父配对或条件核真值。物理模型从已声明的 clean SOURCE 初始化独立拟合相同目标。

原 6593 个合法 TRAIN SOURCE 分为 6465 个本阶段教师训练父事件与固定随机抽取的 128 个后验留出父事件。两类角色都保留完整波形，不按能区挖空。原 A0/M0、PCA、005 已训练于全部 TRAIN，因此这不是全流程未见验证。每组目标统计由 6465 个教师父事件各一次生成确定；FIT、CHECK、FINAL 特征图种子分别固定且不同。

每个种子分别执行神经模型和物理比较器各 12 个完整联合方向。每轮 SOURCE 1024 父×4 draw，目标为独立选择的 1024 父×4 draw；两侧独立遍历全部 6465 个训练父事件。CHECK 使用新父抽样与新随机数，同时使用独立 Fourier 投影。两种比较器使用相同数据和随机数预算、相同轮数；其 54/46 参数造成的实际差分成本分别记录。

差分步长 0.04；完整正规方程 ridge 为 `0.02*mean(diag(J.T@J))`；整体步长 L2 半径 0.40；只允许 1、1/2、1/4 三个固定回溯比例。完整硬输出相对原模拟峰幅的平均 RMS 变化不得超过 8%，99 分位不得超过 25%。异常标志相对旧候选增加不得超过 max(4 行，0.5% 批大小)。这是首轮优化信赖范围，不是硬件精度。

接受要求三种假设平均的白化联合风险至少下降 1%；四个宏块的风险不得超过旧值的 1.15 倍加 `2/N` 的均值特征 Monte Carlo 尺度。不要求每个参数或每项指标分别显著变好，不在接受后冻结子模块。全部判断基于真实 ADC/first-argmax/减基线/256 裁窗输出。

终点在 128 个留出父事件、每父 64 draw 的两套全新独立随机库中比较 M0、物理初始、物理终点、联合终点和教师 oracle。教师配对仅在这里计算条件均值、投影协方差、电荷方差，用实际生成均值而不是零随机头值。原生 wave、QPSD、noise、形态距离、异常计数与分母全部独立报告。

神经模型两种子均须通过：三种噪声假设的联合超额风险较 M0 至少降低 35%；条件均值误差降至原来的 65% 以下且绝对相对 RMS ≤5%；条件协方差误差降至原来的 75% 以下且相对 Frobenius ≤0.50；电荷条件方差为教师的 0.5–2 倍；原生 wave/QPSD 不超过 max(1.02×M0,1.20×oracle)。这些门在训练前固定，不以最好的噪声假设代替其余假设。物理比较器是能力对照，不要求它精确表示神经教师。

另执行一次固定响应的人口诊断：复用同一教师样本计算 nominal、low_h、high_h 三个已登记情景及 ESS，不开放权重网络。两个各 3 轮的附加小试验明确从已知正确响应起步，目标人口均为 high_h，一支故意假定 nominal，另一支使用固定正确 high_h，比较其条件核漂移。这是人口代偿诊断，不能计作响应恢复成绩。

最大 54 个联合方向、162 次候选回溯、2724 列差分。4 CPU、6 GiB GPU 分配上限、12 GiB RSS、1500 秒内部停止、1800 秒外部硬停止、32 MiB 输出。失败保留完整轨迹，不自动重启。教师失败先定位模型表达、随机协方差或优化问题；不直接扩大网络，不进入 REAL 联合训练。教师通过后另行前瞻登记 REAL 校准与必要对照。
