# 003 固定结果的数值交付核验

本计划在实际科学执行前确定。对来源审计检查全 21047 个既有 TRAIN 父的重建与逐事件身份；不添加原始记录或进行新数据筛选。

128 次分类器校准结束后，重新加载全部 128 个固定检查点，用其保存的 TRAIN 内伪留出事件和标准化参数、同设备同批量重新计算全部 128×512=65536 个分数，比较保存分数的逐值一致性。从已保存分数、1000 个 bootstrap 统计量、255 个置换统计量复算 AUC、区间和 +1 p 值，并核对样本/组/训练更新计数。

这是固定结果的序列化与数值重放核验；新增分类器拟合、噪声生成器训练、响应训练均为 0。核验脚本和 native exit/哈希单独留账。不得通过选择某个检查点或重训来修复重放不一致，也不得把数值可重复性称为科学有效性或跨采集验证。
