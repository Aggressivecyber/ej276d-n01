## 唯一新算子

沿用 038 均值算子，仅将原第2坐标设为 f，得到原均值增量 d_i(t)。对每个输入事件定义 L_i = -sum(d_i[100:112])，保留其正负号，不裁剪、不筛选事件。

b_pre 为 (100,126) 内的 sin²(pi*(t-100)/26)，其余为零，离散总和归一到1。b_peak 为 (126,158) 内的 sin²(pi*(t-126)/32)，其余为零，总和归一到1。两端值精确置零，连续原型的一阶导数也为零。

原 canonical-Q 窗口是 [110,366)，不是整条载体。设 k = sum(b_pre[110:366])；b_peak 全部位于该窗口内。附加修正为 c * L_i * (b_pre - k*b_peak)。最终信号 = 原 M0 随机信号 + d_i + 附加修正。

附加修正的 canonical-Q 为零，prefix [0,100) 和尾部 [158,384) 相对原 front 设置逐值不变。原 front 本身的全局归一化仍存在，不能把最终总修正称为只作用于峰前。M0 随机项、005、电子噪声与硬读出不变。每个事件通过自身 d_i 决定 L_i，不输入父行号、REAL 配对或噪声抽样。
