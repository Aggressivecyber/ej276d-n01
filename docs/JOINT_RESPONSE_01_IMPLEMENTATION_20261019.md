模型以冻结的完整 SOURCE→A0 和 M0 八个电压基为输入。六个有效坐标为增益、前沿时间尺度、下降沿尺度、慢尾幅度、尾部时间尺度、峰顶曲率。条件函数使用 `[1,tanh(logQ/2),tanh(PC1/2),两者乘积]`，24 个均值系数。6×6 下三角矩阵的 21 个系数作用于已有八个高斯变量的前六个；另有 8 个 M0 模态尺度，共 53 个响应参数。所有系数在同一点构造完整 Jacobian 并联合求解。

逐次生成的坐标为 `a_max*tanh(mean(c)+L*z[:6])`，`a_max=[.30,.50,.50,.45,.40,.30]`。三个时间坐标控制正的局部时间速度，积分后将软件载体端点 100 和 383 固定，内部峰位置可移动；此端点约定不是到达时间标定。慢尾和峰顶采用正的平滑幅度因子。没有逐事件 Q、front、tail 或峰索引等式。参数系数范围 ±1、M0 尺度范围约 0.707–1.414 是首轮研究信赖范围，不是硬件置信区间。信号前 100 点保留零支持。
