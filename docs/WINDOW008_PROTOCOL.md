# N01 256点有效窗口版本008

用户于2026-10-13要求缩短并对齐实际使用的256点窗口，同时授权Astra Max Fast子智能体并行施工。Gamma同源文件哈希及代码确认：256是峰前16到峰后239、1ns/点的分类输入时间范围；原始采集为10000点。这里只采用其有效时间范围，保留N01已绑定的20点均值降采样、电压、ADC口径，不复制Gamma的额外软件噪声、倍增益、峰归一化或限幅。

最终训练损失、判别器、评价和交付波形均为256点。为执行相同的原100点基线扣除和含噪重新寻峰，内部神经网络及观测使用384点载体，网络层级为384/192/96/48/24，32/48/64/96/128通道。内部384不能称为256网络输入，也不要求有384点连续纯静默实测。原480结果保留，不从旧权重续训。

共同观测算子为：一次原N01 ADC，原索引[0,100)均值扣除，在[112,144)用first argmax寻峰，再取[p-16,p+240)。REAL由既有canonical loader提供已ADC电压，不重复ADC；清洁解析SOURCE不经过ADC，只做同坐标的基线与裁窗并保留原384载体。搜索边缘和全局峰在搜索外逐行计数，不删行、不扩窗、不补零，也不用于修改本次配置。这个搜索范围是本版本软件定义，不是已核验的硬件触发范围。训练数据全6593个SOURCE父事件和21047个REAL事件均保留；DEV身份与角色保留，波形不用于准备或训练。

观测Q定义为256点电压之和乘1ns；tail从裁后46到255，即峰后30ns起。PSD保留带符号实测值，不裁到[0,1]。分箱、尺度和数值保护重新由全部TRAIN拟合。信号Q头的canonical积分是载体[110,366)，峰锚126。重新寻峰可能改变最终积分端点，故独立报告Q信号在观测窗的变化，并在相同最终裁窗下分解信号、噪声与ADC贡献。旧固定窗口的Q恒等式不冒充新的观测恒等式。

纯信号前100点严格为零；原65点因果滤波、联合10维随机头、8条形状基、局部零canonical-Q信号涨落保持分解意义。384末端不强制零。时间变换越出载体时使用已记录的64点Hermite数值延拓，返回越界查询数量，不把延拓当作实测。电子学保持冻结005的有效100点随机模型；三个固定条件协方差假设延拓到384，保留完全相同的100点前缀，并在基线与脉冲上共用同一随机实现。三假设是敏感性分析，不构成未知长时相关的置信集合或物理识别。
