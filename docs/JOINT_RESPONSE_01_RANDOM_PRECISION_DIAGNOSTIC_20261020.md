# JOINT_RESPONSE_01：固定端点随机估计精度诊断

2026-10-20前瞻登记。原三轮REAL校准与五项固定方向检查全部保留原判定。固定中心的对角曲率/一次混合修正/两次混合修正三候选序列已闭合，不再加修正项。

保存证据表明，两头当前中心在FIT0已有初值QPSD保护线外的值（最大1.010624/1.015118）。seed0完整Jacobian有38/54个Gram特征值小于原ridge，后两候选76%/81%的参数步长平方位于这些方向；两步夹角余弦0.0432，但实际FIT joint剩余仅从0.965653变为0.965822。增加一次曲率项未稳定参数方向。将初值native不退化与每FIT至少1%joint改善同时写入局部凸模型，或按已测FIT正预测误差保留余量，seed0均不可行，并有独立对偶证书。此结论仅限保存局部近似，不证明真实响应不存在可行解。

本项隔离随机估计波动：固定原两头第三轮起点、原FIT0的1024父/4096 REAL、原joint投影2026103101和native投影2026103111、54参数和±0.004差分。原生成器、电子学、ADC、峰选择、裁窗及指标实现不变。只比较同成本的IID32与ANTITHETIC_Z32；后者每父将前16个8维高斯潜变量与其相反数配对，电子学噪声仍为原32份IID生成结果，逐字节与该重复的IID方案共用。每个边际仍为原高斯输入，联合draw之间相关；不称32份独立draw，也不声称经验W1或平方风险因此无偏。

每头4组新随机库，组间和头间独立，组内两方案配对共享电子学噪声及前16个潜变量。基种子202680100000，头间+1000000，重复间+10000；噪声+1/+2。与此前流不重叠。每个方案重新计算完整54列Jacobian、native Jacobian和非负对角曲率。固定检查前两已测候选curvature_update和second_curvature；不求新方向、不选端点、不提交更新。每头先按原FIT0旧流精确重放当前、初值和两个候选，后续新库都在相同记录/投影上，区分随机库波动与读出非线性。

潜变量成对只是待验假设。[Owen的方差缩减教材第8.2节](https://artowen.su.domains/mc/Ch-var-basic.pdf)给出对称输入反射方法，并说明其收益依赖被积函数，可能反而增加方差。本项目只反射响应潜变量，保留独立电子学噪声，必须以实际配对结果判断，不从一般结论推定有效。

报告每头每方案4组完整J/N，逐参数组、native分量、Gram谱和两个固定候选的线性/对角曲率预测误差。主诊断量：四组J的离均值Frobenius平方和除以3；native wave/QPSD导数先用两方案共8组当前native均值作共同尺度，再同样计算离散度。noise单独报告，不纳入潜变量方案的主要改善量。双方同一分母，因此离散度比可直接比较。

支持进一步估计器核查的前瞻门：两头均须J离散度比≤0.75、native wave/QPSD导数离散度比≤0.75；平均J范数比在0.80—1.25；两个固定候选、四库、三噪声假设上平均绝对native wave/QPSD二阶预测误差不增。25%为本诊断要求的实质改善幅度，不是统计置信保证。四组仅提供有界方法诊断；无论通过与否均不自动进入训练或阶段5，原科学门不变。
