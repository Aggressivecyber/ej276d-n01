# 按 job163 归因修复均值条件路径

用户 2026-10-21 要求“去修复”。job163 已定位波浪到旧 A0 的 Q／幅度条件神经残差；仅训练末端 247 参数没有移除它。本轮解冻复制 U-Net 的条件 MLP、FiLM 仿射层和末端均值卷积，同时保留原有 53 个联合响应参数，共 273174 个可训练参数。原始模型、复制网络的其余卷积与归一化、均值时间映射、电荷映射、随机 M0 基与电子学不更新。

数据角色和成功标准：全部 6465 FIT 源父、18948 REAL FIT 保留人口权重；REPORT 不进入训练、归一化或选择。沿用固定多尺度 Q/CDF 和条件波形记忆，以及所有旧终点门槛。新增两主要源形状分支的完整波形曲率和固定窗口 PSD 反复起伏指标均至少减半的要求。通过 FIT 仅允许进入固定 REPORT 评价，不等于物理响应匹配成立。Q 是电荷，未标定物理能量。

实际趋势项：在两条已声明的 FIT 源形状分支上构造平均归一化形状，各取自身支持范围内 128 个等距 logQ 条件。幅度随同一形状的 Q 缩放。计算规范电荷归一化的完整 384 点均值波形对 logQ 的二阶差分平方均值；每分支按继承值归一化、等权加入目标。它限制波形族的弯曲程度，不要求某条物理趋势必须单调。其他 164 个源父保留在全部分布损失和硬检查中。

梯度按源父缓存均值，先汇总所有随机抽样的伴随梯度，再按相同父分块重算 U-Net。这与保留所有父分块计算图的导数一致；GPU 合成测试最大绝对梯度误差 8.94e-8。一次 Adam 提议与波形、条件波形、趋势、先前明确阻塞的 L16_04/L64_26 两单元及两库 ADC 风险梯度构成最多 8 个方向。每个方向均用真实 ADC/寻峰/裁窗测量，在线性组合后再做原生硬检查。最多 24 方向、连续 3 次拒绝停止；不追加步数、不放宽阈值。

工程接续：job164 因 REAL 嵌套 flags 字典未移到 GPU 而退出，0 方向、0 更新。job165 补齐搬运后，在起点重现检查退出，仍为 0 方向、0 更新。追加登记的固定权重诊断发现新旧输入特征和条件完全相同，但 U-Net 重算相对旧缓存存在与分块有关的数值差异：64 行块最大 0.000586622 V，128 行块最大 0.000177189 V。没有放宽 1e-7 V 起点门槛。

job166 使用零起点函数差值：M_new(x)=M_inherited(x)+qbar(x)[U_train(x)-U_initial(x)]。U_initial 与 U_train 使用相同父分块、相同初始网络和完整规范电荷归一化。起步时差值逐位为零，随后梯度进入复制的条件路径。三个项均由 SOURCE 波形和条件计算；行号只寻址已计算缓存，不输入网络。规范电荷差分为零，保留 qbar；推理需按该固定分块协议构造初始函数缓存后加载新权重。趋势网格使用该函数在连续条件上的规范表示，终点另对真实 FIT 父事件的最终均值计算起伏指标。

数值自检保留边界：最初 GPU 测试把不同批形状的直接前向与父分块重放比较，最大梯度差 0.0005275、相对 L2 差 0.000672，不能声称该比较逐位一致。改用与实际算法相同父分块的完整保图基准后，在原有容差下通过，未放宽容差。重放的数学等价不意味着改变 CUDA 批形状后舍入相同。
